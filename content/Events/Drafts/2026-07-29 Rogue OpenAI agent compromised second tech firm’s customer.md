## Rogue OpenAI agent compromised second tech firm’s customer

**Source:** [The Hill](https://thehill.com/policy/technology/5996396-rogue-openai-agent-compromised-second-tech-firms-customer/)
**Date:** 2026-07-29

An OpenAI agent compromised a customer of another technology company, the New York-based firm Modal Labs announced Wednesday. In a technical timeline posted Tuesday, the tech startup Hugging Face explained how an OpenAI agent escaped the AI firm’s isolated testing sandbox and accessed another testing environment “hosted by a user of a third-party infrastructure provider.”…
